# Coming Soon Page

A clean and simple coming soon page for Stux.Design.

## Overview

This repository contains a lightweight HTML page designed to let users know a Stux.Design service is on its way. It's perfect for building anticipation ahead of launch.

Like its siblings it's a single static page, but drawn as a designer's artboard: a faint layout
grid, rulers along the edges, a selection box around the headline's highlighted words (tagged
"Draft") and crop marks on the card, all in Stux.Design magenta (`#e71081`).

## Features

- 📄 Simple, clean HTML structure
- ⚡ Lightweight and fast-loading
- 🎨 Ready to customize
- 📱 Responsive design
- 🚀 Deployed at [soonpage.stux.design](https://soonpage.stux.design)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/StuxDesign/soonpage.git
   ```

2. Run `./dev-server.sh` (or `dev-server.bat` on Windows) and open `http://127.0.0.1:8000`.
   DEV_MODE is on by default, so the dev banner shows; pass `--no-dev-mode` to see the page as
   production does

## Customization

Edit the HTML files to:
- Update the coming soon message
- Add your branding and logo
- Customize colors and styling
- Include email signup or social links

## Deployment

This project uses GitHub Pages and can be automatically deployed to your desired domain.

The live version is deployed at [soonpage.stux.design](https://soonpage.stux.design).
